# 🔐 Password Strength Checker

### 🛡️ Check Your Password Strength Easily!

A simple and interactive **Password Strength Checker** built using HTML, CSS, and JavaScript. It checks common password requirements and gives instant feedback. ⚡

---

## ✨ Features

🔐 Password strength checking
✅ Minimum 8 characters
🔠 Uppercase letter detection
🔡 Lowercase letter detection
🔢 Number detection
🔣 Special character detection
📊 Instant strength feedback
🎨 Clean and attractive interface

---

## 🛠️ Technologies Used

🌐 **HTML** – Web page structure
🎨 **CSS** – Styling and responsive design
⚡ **JavaScript** – Password validation and strength checking

---

## 🚀 How It Works

1️⃣ Enter a password in the input box.
2️⃣ The application checks different password requirements.
3️⃣ Each requirement is marked as passed or not passed.
4️⃣ The password receives a strength level.
5️⃣ The result is displayed instantly. 🎉

---

## 📊 Password Strength Levels

⚠️ **Weak** – Few requirements are satisfied.

🟡 **Medium** – Most requirements are satisfied.

🟢 **Strong** – All major requirements are satisfied.
